# Stage 0-1: Ergo CPU eigensolver — oracle validation

Programs: `stage0_power.ergo` (generated by `gen_ergo_stage0.py`, 3.3 MB
source with DATA-statement index/coefficient tables, column-major) and
`stage1b_dense.ergo` (Stage 1b: COO dense build + dense matvec).
Compiled with `python -m core <file>.ergo -o <binary>` (from repo root);
compile time ~2.1 s each. No PROGRAM wrapper, ENDDO/ENDIF one word,
block IFs only, STATIC for subroutine-touched arrays — all respected.

## Convergence behavior

- Ground run: **618 iterations** to |Δρ| < 1e-12. Better than the naive
  estimate (~1400) from the dominance ratio |E1−3|/|E0−3| ≈ 0.98 — the
  Rayleigh quotient converges as ratio² per step and the seed has good
  overlap. No shift adjustment needed (shift 3.0 baked into DIAG; the
  math: |E0−3| = 5.86 > |Emax−3| ≈ 4 keeps the ground state dominant).
- Deflated run (Gram–Schmidt against GS each iteration): **201
  iterations** — faster than the ground run (the E1↔E2 separation is
  larger than E0↔E1 at this point).
- Deterministic MOD-based seeds; DOT_PRODUCT/NORM2 intrinsics used as
  specified (whole STATIC arrays, REAL, rank-1).

## Notes / gotchas encountered

- Physics choice that made this clean: at B = 0.25 the first harmonic
  V = K_PHASE − B·K_BIAS = 0 exactly, so H is REAL in the original gauge
  (kinetic + real −J/2 bonds) — no complex split needed at the oracle
  point. The generator asserts this.
- Two bugs caught pre-validation: (1) kinetic diagonal formula in the
  generator dropped the +1/2 per site (fixed before first compile);
  (2) the dense matvec applies H̃ = H − 3I, so its Rayleigh quotient
  needed +SHIFT (caught on review before running).
- DATA-statement tables at 3.3 MB compiled without issue (2.1 s) — the
  V22 pattern (everything precomputed) is viable at this size.
- Dense path is ~330× slower than sparse per iteration (43M vs 315k
  multiply-adds) — expected; its purpose is validating the FLOW-scatter
  dense build (`CALL ZERO(HD)` + unique-entry scatter), the form that
  extracts to a GPU kernel per the port spec. Arena memory: HD is
  344 MB and fit the default 1 GiB arena without --arena-size.
